# Prodanoff Audio Cut

**A simple, free audio cutter for Windows.**

Prodanoff Audio Cut is a lightweight desktop application for cutting, previewing, and exporting audio from WAV and MP3 files.

Designed for a simple workflow without unnecessary complexity.

## Features

- Import WAV and MP3 files
- Interactive audio waveform
- Precise selection and trimming
- Zoom and timeline navigation
- Audio playback and selection preview
- Adjustable Fade In and Fade Out
- Export selected audio to WAV or MP3
- Portable — no installation required

## Download

The latest version will be available from the [Releases page](https://github.com/prodanovf/ProdanoffAudioCut/releases).

**Windows x64 | Version 1.0.0 | Free**

## How to use

1. Download the Windows ZIP archive.
2. Extract it to a folder.
3. Run `ProdanoffAudioCut.exe`.
4. Open a WAV or MP3 file.
5. Select the section you want to keep.
6. Adjust Fade In and Fade Out if needed.
7. Export your selection as WAV or MP3.
